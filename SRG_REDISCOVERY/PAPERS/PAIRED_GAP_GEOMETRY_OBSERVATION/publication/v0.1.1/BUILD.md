# Reproducing Paper I v0.1.1

The published PDF is the accepted artifact. It was not regenerated for publication. A local reproduction may differ in PDF metadata or toolchain output and does not replace the accepted bytes.

## Work in an isolated copy

Copy this entire edition directory to a new writable working directory outside the authoritative checkout. The source entry is `manuscript.tex`; all five required figure PDFs are included under `figures/`. The typesetting dependency graph contains no author sketch, private review archive, project model or private account path.

The included `tools/build.py` is the unchanged accepted helper. It creates `build/` and `cache/`, invokes an existing Tectonic compiler in cached/untrusted mode, and writes the reproduced PDF in that working copy. Consequently, do not run it in the frozen publication directory.

## Existing prerequisites

Use an existing Python 3.11-or-later environment and a Tectonic 0.17-compatible executable with a populated offline cache. The source requires article, amsmath/amssymb, fontspec/unicode-math, mathtools, booktabs, array, graphicx, xcolor, fancyhdr, geometry, hyperref and needspace. The cached fonts are TeX Gyre Pagella (including its math font) and Latin Modern Mono. No compiler, dependency package, cache or font files are distributed in this edition.

The manuscript-local checker additionally uses SymPy and NumPy; optional static figure reproduction uses NumPy and Matplotlib. Their recorded manuscript-review versions were Python 3.11.15, SymPy 1.14.0 and NumPy 2.4.4 on Windows. Other toolchains have not been certified for byte-identical PDF output by this publication.

In Windows CMD, from the isolated working copy, set `PAPER_I_TECTONIC` to the actual path of your existing compiler and `PAPER_I_TEX_CACHE` to the actual path of your populated cache. These are user-supplied environment values, not paths supplied by this edition. Then run:

```bat
set PYTHONDONTWRITEBYTECODE=1
set PYTHONUTF8=1
python -B -X utf8 tools\build.py
```

The helper requests `--only-cached --untrusted`, uses the retained metadata epoch, and records the command and compiler identity in its working `build/` directory. Missing prerequisites are reported rather than downloaded by that helper.

## Optional manuscript-local checks and static figures

These are separate from typesetting. In the same isolated working copy:

```bat
if not exist cache mkdir cache
if not exist evidence mkdir evidence
if not exist figures mkdir figures
python -B -X utf8 tools\check_manuscript.py
```

The unchanged checker writes `evidence/manuscript_checks.json` and reads the three included JSON inputs under `input/retained_srg02`, `input/retained_srg03` and `input/retained_srg04`. It checks the manuscript's displayed formulas and finite examples, not an earlier research suite or the native kernel. Its preserved 21-pass record is historical validation; a reader's run is a new local result.

To reproduce the static figures in that working copy only:

```bat
python -B -X utf8 tools\render_figures.py
```

The renderer replaces its five figure sets and `figures/figure_data.json` in the working copy. It reads retained coordinates, orientations and existing example data. No trajectory is simulated. Presentation and font-library differences can affect generated bytes.

## Visual and mathematical verification

Any newly compiled PDF needs its own inspection of every page. The accepted article had 25 pages, five computed figures, 21 manuscript-local checks and a separate 17-item editorial closure. Those numbers are not automatically transferred to a new build. Internal review is not external peer review.

The original private build ledgers, editorial-comparison scripts and one-time intake/packaging helpers are intentionally not included and are not necessary for these reproduction commands. The private author sketch and full private review bundles must not be added to this public edition as build dependencies.
