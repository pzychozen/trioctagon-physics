## Boundary with existing software

The repository already contains a separate [fixed November SRG operator and initialization handoff](../kernel_physics/srg.py). That code's documented role is an initialization map, not reproduction of Paper-A evolution or implementation of the full SRG-I historical programme. This research area adds no runtime dependency or authority over the kernel, UI or accepted geometry.

The completed Tower II audit, future SRG-II writing, any newly specified standalone SRG model and possible mathematical comparisons remain separate decisions. No new experiment, combined recurrence or application integration is introduced by this publication preparation.
