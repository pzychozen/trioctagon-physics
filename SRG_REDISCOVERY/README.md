# Symbolic Resonance Geometry — standalone research

**Standalone SRG research. This reconstructed research programme is not integrated as dynamics into the Tri-Octagon kernel or application. Recovered historical definitions, established mathematical results, unresolved questions and proposed future models are distinguished explicitly.**

[Foundational reconstruction v0.1.1](PAPERS/SRG_I_FOUNDATIONAL_RECONSTRUCTION/publication/v0.1.1/README.md) is accepted within internal manuscript scope, with E01–E03 closed. ## Boundary with existing software

The repository already contains a separate [fixed November SRG operator and initialization handoff](../kernel_physics/srg.py). That code's documented role is an initialization map, not reproduction of Paper-A evolution or implementation of the full SRG-I historical programme. This research area adds no runtime dependency or authority over the kernel, UI or accepted geometry.

The completed Tower II audit, future SRG-II writing, any newly specified standalone SRG model and possible mathematical comparisons remain separate decisions. No new experiment, combined recurrence or application integration is introduced by this publication preparation.

## Contents and reuse

This is a curated public candidate, not an upload of the local research workspace. OLD_MATERIAL, the R0–R3 investigation directories, local drafts, full review packages and closure-filing records remain preserved outside this subset.

The [repository license scope](../LICENSE_SCOPE.md) excludes scientific research from automatic Apache-2.0 coverage. This preparation grants no new license to the manuscript. Existing source-specific notices, including CC BY 4.0 for identified deposited originals, are retained and attributed.
