### 3.2 Ordered transition

[model_core.py](C:/TORMENT/TRIOCTAGON_new/kernel_TO/model_core.py): `ModelParams` 35–64; `ModelState` 72–102; `phase_lock_step` 133–162; `update_z` 169–230; `step` 246–266. Let the held old state be \((\Omega_n,q_n,t_n)\), with fixed parameters unless an override is explicitly passed.

**Amplitude and channel mixing.** All components first use the same old Ω:
\[
L_3=\begin{pmatrix}-2&1&1\\1&-2&1\\1&1&-2\end{pmatrix},\qquad
V=\Omega_n+\varepsilon\Omega_n\odot(k-|\Omega_n|^2)+\delta+gL_3\Omega_n.
\tag{1}
\]
The componentwise cubic term tends to increase small amplitudes below their target and decrease amplitudes above it, subject to the actual discrete step. The Laplacian mixes channels by differences: the balanced direction has eigenvalue zero and transverse directions eigenvalue −3. This is channel geometry. A stability guarantee for arbitrary ε,g,k is not implied. `delta` defaults to complex zero; `g_override` can replace g. The caller above does not supply overrides.

Claude correctly flags that the balanced line is generally **not invariant under the full heterogeneous-k map**. For Ω=a(1,1,1), δ=0, the pre-sync components are \(V_j=a[1+\varepsilon(k_j-|a|^2)]\). For nonzero a with all brackets positive, unequal k gives unequal amplitudes, and phase-only synchronization cannot restore equality. This applies to both the raw scaled and soft ladders; the review's soft ladder is not `ModelParams()`'s default. L3 and the three-node synchronization submap are S3-equivariant, but a fixed unequal k breaks nontrivial channel-permutation symmetry, including the cyclic permutation. Relabelling k alongside Ω is covariance between parameterized systems, not a symmetry at that fixed k. The review's separate “only cyclic relabelling” statement is therefore not accepted. Modern global-phase qualifications at zero components remain as in section 9.

**Harmonic-three phase synchronization.** [phase_triad_sync.py](C:/TORMENT/TRIOCTAGON_new/kernel_TO/phase_triad_sync.py), `apply_phase_triad_sync` 5–28, writes \(V_j=r_je^{i\theta_j}\), and simultaneously applies
\[
\theta'_j=\theta_j+\lambda_{\rm phase}\sum_{\ell=1}^3
\sin[3(\theta_\ell-\theta_j)],\qquad
\widetilde\Omega_j=r_je^{i\theta'_j}.
\tag{2}
\]
This rotates phases while retaining the amplitudes of V. The factor three makes phases separated by 120° indistinguishable to that harmonic; it does not create a spatial octagon. Default λphase=.001. With λphase=0 the function returns immediately. At zero components, historical NumPy angle conventions and modern `arg0` need the qualification in section 9.

**Optional dynamical noise, then commit.** If `omega_noise_sigma>0`, core lines 155–158 add \(\sigma(\xi+i\eta)\), using two global NumPy Gaussian draws, after synchronization. Otherwise \(\Omega_{n+1}=\widetilde\Omega\). Default σ=0. When noise is enabled, the global RNG stream belongs in a reproducibility/state description; the driver's local initialization RNG and the `run(seed=...)` metadata do not seed that stream.

\[
q_{n+1}=(q_n+\mathrm{phi\_step})\bmod N,\quad
t_{n+1}=t_n+dt,\quad \mathrm{step}_{n+1}=\mathrm{step}_n+1.
\tag{3}
\]

Reducing dt at a fixed nominal horizon changes the number of nonlinear iterations, not merely an integration resolution of a displayed Ω ODE.

### 4.2 Exact RSB transition

[rsb_model.py](C:/TORMENT/TRIOCTAGON_new/kernel_TO/rsb_model.py): `RSBParams` 14–42; construction 60–77; channel matrix 98–131; Hamiltonian action 204–240; contraction 242–298; reinforcement 300–316; `step` 321–353; `run` 355–395. Using a=αL,b=βS, the **channel recursion** is
\[

\tag{8}
\]
It mixes visible/L, phases S, branches visible amplitude into L/S, then damps visible amplitude. Branch fractions are validated; this product is generally nonunitary.

The **ring/helicity step** is
\[
\mathcal H=\kappa_LP_L\otimes\Delta_M\otimes I+
\kappa_SP_S\otimes\Delta_M\otimes\sigma_z+
\mu(P_L+P_S)\otimes M_{phase}\otimes\sigma_x,
\]
\[
\psi^{(2)}=\psi^{(1)}-i\epsilon_{RSB}\mathcal H\psi^{(1)}.
\tag{9}
\]
Δ transfers amplitude between adjacent phase labels; σz reverses the S-channel Laplacian sign between helicities; σx swaps helicities in L/S. This is explicit Euler, not an exact unitary exponential. `_build_phase_mask` 144–154 evaluates \(\cos(M\,2\pi m/M)=\cos(2\pi m)\): mathematically constant 1, up to floating evaluation. It does not implement CP windows. The assignment-based ring constructor has coincident-neighbor issues at M=1/2; the usual cycle formula applies for M≥3, including 12.

The **fixed reinforcement** then applies
\[
\psi^{(3)}=\operatorname{diag}(e^{-\eta/2},e^{\gamma/2},e^{\gamma/2})\psi^{(2)}.
\tag{10}
\]
The UI's γ described as “damping” actually gives L/S gain here. This “REFU-like” stage is a fixed matrix; it does not integrate a memory H.

The **state-dependent selector** computes post-core band energies
\[
E_m=\sum_{c,h}|\psi^{(3)}_{cmh}|^2,\quad m_0=\arg\max E_m,
\quad \psi^{(4)}=(1-a_{eff})\psi^{(3)}+a_{eff}P_{m_0}\psi^{(3)}.
\tag{11}
\]
For α≤0 it returns unchanged. Otherwise aeff is clipped α, or, in adaptive mode, clipped \(\alpha[-\sum p_m\log(p_m+10^{-12})]/\log(M+10^{-12})\), with \(p_m=E_m/\sum E\); zero total gives zero gate. `argmax` chooses the first tied maximum. It operates directly on the phase-index tensor; no Fourier transform converts these slices into Fourier spectral coefficients. The chosen slice is retained and the others reduced. The selector is recalculated from current ψ and not stored as an independent memory coordinate.

Finally \(\psi^+=\psi^{(4)}/\|\psi^{(4)}\|\). Zero poststep norm instead requires an RNG and draws a new normalized Gaussian tensor; without RNG it raises. Nonzero deterministic evolution is common-phase equivariant and can mathematically descend to CP71 at default size, but code retains the phase. It has 72 complex entries and unit norm, not 24 spatial vertices.
