VIEWER
  Open BOUNDARY11_VIEWER.html in a normal WebGL-capable browser. The file embeds
  Plotly and its data; it has no external script or data dependency.
  The Codex browser's policy does not permit file: navigation, so browser QA was
  performed via a loopback-only Python server. No alternate file-access mechanism
  was attempted. To use the same optional preview method from Command Prompt:
    python -B -m http.server 8765 --bind 127.0.0.1 --directory .
  Then open http://127.0.0.1:8765/BOUNDARY11_VIEWER.html

All geometry layers have independent switches. Original edges always remain.
Gold dots indicate coincident or selected branches; orange crosses indicate the
secondary radial projection. Use the exact-event buttons rather than rounding
their radii. Export retains 42 labelled rows even when there are 18 unique dots.
Floating drawing tolerances can visually merge nearby points; the exact inventory
and report define mathematical counts. The initial R/w=1 is illustrative only.
