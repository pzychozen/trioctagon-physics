# Same-Trajectory Native Credit in the Reciprocal Chiral Exchange Candidate

*A finite-coupling theorem for an initially empty carrier and receiver*

**Hilmir Frímann Halldórsson (pzychozen)**. **v0.1**, **10 pages**. Publication preparation: **3 November 2026**.

Author-authorized repository research edition. Scientific manuscript review and the focused final artifact check are complete; MC-01 is closed. The PDF and scientific sources are the exact accepted artifacts.

The paper proves an explicit sufficient finite-coupling regime in the reciprocal chiral exchange candidate: a solution starting with an empty carrier and receiver first supplies native trial storage and later has strictly negative total native power on that same solution. The proof retains propagation, native drift and an initially active receiver. Later native credit recovers earlier supplied storage; it does not establish a substantial returned fraction, the exact receiver-power sign at the witness, or the intended spatial toroidal route.
