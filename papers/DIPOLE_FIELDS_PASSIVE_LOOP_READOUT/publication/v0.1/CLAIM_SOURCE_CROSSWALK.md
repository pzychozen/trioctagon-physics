## Conditions and limits

- **C01:** Positive observation gain and propagation speed; signed tangent aggregation is proposed.
- **C02:** Positive source/receiver radii and nonzero axial separation. One exact sample applies only to the aligned single-source control. Circle-center and body-center probes differ.
- **C03:** The disk is a mathematical integration device. The test placement is not an inherited H/R ring location.
- **C04:** Away from source wire; filled-disk argument requires separation from that disk. No SI calibration, autonomous receiver law or electromagnetic speed follows.
- **C05:** Whole-disk smoothness and clearance; stronger derivative bound uses clearance from filled source disks, not only their rims.
- **C06:** W is not host width w. Instantiating three simultaneous carriers is an added modeling choice.
- **C07:** Zero centered moment does not imply zero complete carrier state or exterior field.
- **C08:** Instantaneous ambiguity; the states are not asserted to be adjacent iterates or indistinguishable after arbitrary native updates.
- **C09:** Returning waves can change the mean. An empty preparation remains zero before the first return; no universal assignment from W is supplied.
- **C10:** Planar W, equal lengths and positive equal storage weights. Scale alpha is not RX native-storage alpha_N.
- **C11:** Correct matching tracks only across the added jump. Active RX evolution need not preserve it; a held source-off plateau is an explicit premise.
- **C12:** Ordinary native map remains unchanged. Carrier launch itself is added; source weights are in A,B,C = circle 2,0,1 order.
- **C13:** The cost 6.768750025e-9 L alpha^2 is not paid automatically by native intensity or GM01–GM03 stores. A physical donor is unprovided.
- **C14:** Only the W-driven part reverses; beta_0 e remains. Equal aggregate leading moment does not identify the complete field of displaced circles.
- **C15:** Source-off held plateau, Q=[ey,ez,ex], circle center O+R ez, body center O+(R-wKc)ez, b=a=wR_Gamma.
- **C16:** Error bounds the disk average relative to the central leading component. Distinct-center translation contributes O(R^-4); this is a sufficient configuration-specific range, not an optimal threshold.
- **C17:** Additional equally spaced exact signed vector samples reassembled in ambient coordinates; not the old body-center array. Fixed N is certified at the benchmark only. Tangent error adds 2 epsilon/b.
- **C18:** Straight-distance retarded kernel and held constant sources. Earliest delays may differ; equality concerns latest delays. Strict post-maximum waiting ensures neighborhood smoothness.
- **C19:** The measured quantity is a scalar disk average. Ambient projector is rotated by Q; actual different circle centers prevent treating all averages as one pointwise vector.
- **C20:** Upper and lower paths each have six actual edges; upper path is not planar. They are separate from the tested receiving circle. WT loaded state is not a second native triad.
- **C21:** No autonomous magnetic force or receiver backreaction is established. Publication adds no new scientific or production change.
- **C22:** The factor 24 is an absolute operator-norm bound; source-disk Taylor integration gives the stated remainder coefficient.
- **C23:** Saved values only; no new quadrature, scientific suite or stability investigation was run during manuscript preparation.
- **C24:** Prior scientific check counts remain historical evidence. This author-approved publication supplies regenerated document records and a science-only selection.
