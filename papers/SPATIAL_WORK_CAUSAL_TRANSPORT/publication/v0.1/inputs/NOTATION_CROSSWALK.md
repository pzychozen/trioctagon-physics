# Required notation crosswalk

The following distinctions already exist in the sources. Codex may make editorial symbol choices but must record them consistently and preserve meaning.

| Concept | Recommended paper notation | Collision to avoid |
| --- | --- | --- |
| Native complex state / real coordinates | Ω; x=(a_N,b_N) | Boundary wave signals a,b. |
| Native quadratic chiral drive and derivative | f(x), J_f(x) | New duplication J and raw historical chiral C. |
| Original finite carrier-profile map | Bcal or `\mathcal B` | A pointwise Gram matrix B(X). |
| Carrier state | Q=(p,r_c) | Radius r and receiving field. |
| Original carrier speed | c_car | Boundary c and observation speed c_e. |
| Observation/delay speed | c_e | Carrier speed; neither selects physical calibration. |
| Duplication and spatial mixer | J, C | Native derivative/observable. |
| Same-time spatial adjoints | J*, C* | Temporal history adjoint K_G*. |
| Complete-history C6 operator | K_G | Zero-extended K_G,0 and whole loaded drive. |
| Old receiver | z, H_R | New receiving field ζ, H_G. |
| New boundary signals | a,b,c,d | Native real/imaginary vectors and source speed c. |
| Native map | F_native | Added carrier force F_added or calligraphic F. |
| Static geometry parameter | τ_g | Physical time t or channel age ξ. |
| Geometry height/observer coordinate | z_geom or z_obs, with source mapping | ζ now denotes the receiving field; old z denotes the receiver. |
| Carrier and G arclengths | s, dℓ_X; L, M | Physical area, normal flux or channel age. |
| Channel time/age coordinate | ξ in (0,θ_X(s)) | Embedded spatial length or carrier arclength. |
| Delay bounds | θ_- and θ_+ | Exact optimized physical travel times. |
| Full ball radius | R_ball or explicit source R_0 | Cylindrical radius ρ and carrier circle radius. |
| Native and new receiving weights | α_N, β_R, β_G | The old and new β weights have different abstract dimensions. |
| Observation gain | a_o=g_o/(4π) | Native synchronization parameter g. |

Use the original source map and native tuple exactly. The manuscript must define every notation change before use. If a symbol from an earlier geometry figure is renamed, update the figure, caption and text together.
