# Build and document verification

The delivered PDF is the frozen Stage A review artifact. Rebuilding creates a new artifact identity that must be checked; later publication approval is not permission to silently replace the reviewed bytes.

The supplied manuscript/build.py is a document-only standard-library helper adapted from P3. It takes an existing cached Tectonic executable, uses --only-cached and --untrusted, and directs all intermediates outside the candidate edition. No package installation or scientific computation is required.

From the candidate edition in Command Prompt:

    call conda activate torment
    python -I -B manuscript\build.py --tectonic C:\TORMENT\TRIOCTAGON_new\reconstruction\publication\paper_C\build\tools\tectonic\tectonic.exe --build-dir C:\TORMENT\TRIOCTAGON_new\research\NATIVE_FINITE_CAPACITY_ACCESS_PAPER_01\rebuild

The actual final build used Tectonic 0.17.0 and conda torment Python 3.11.15. SOURCE_DATE_EPOCH is the manuscript date, 4 November 2026 UTC; the receipt separately records the actual build time. Windows fontconfig settings are process-local and generated in the external build directory. No standalone fonts are included.

verification/BUILD_RECEIPT.json records the exact command, source/helper hashes, compiler and interpreter, PDF bytes/hash and actual build time. Final main.log, compiler.txt and main.aux are in review_support/build in the review ZIP. The final log has no warnings, undefined references, missing glyphs, underfull or overfull boxes. Three edition hyperlinks, five bibliography entries, 48 labels and 19 bookmarks resolve; all 17 PDF font resources are embedded.

Two early cached-only attempts failed because a 12-point italic subtitle font and a math-square font were absent from the cache. The subtitle was set upright and the proof-end symbol uses the standard amsthm outline box; no font was installed and the scientific text was unchanged. A subsequent successful draft received a citation separator and a page-flow adjustment before the final rebuild. All 11 final pages were rendered again and inspected.

Document extraction and structural checks used the bundled pypdf runtime, with the torment environment activated. Page images were generated by bundled Poppler pdftoppm 26.07.0 at 125 dpi. verification/VISUAL_REVIEW.json binds every inspected image to the final PDF hash. The document checks and fidelity assessment do not constitute GPT/author manuscript acceptance.
