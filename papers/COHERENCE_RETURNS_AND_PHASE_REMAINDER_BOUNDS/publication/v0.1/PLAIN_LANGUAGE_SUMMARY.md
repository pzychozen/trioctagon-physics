# What this draft establishes

The model already evolves. Its complex state changes, decoded vectors can change, and the existing observer has staged and memory-dependent forms. The unresolved question is how any of that would produce the particular cone-pair sequence the author pictured.

The paper distinguishes a repeated pattern from a fully repeated state. Raw coherence keeps relative channel information and amplitude, but hides one shared complex phase. If a regular block returns to the same raw coherence, the state returns up to exactly one unit phase multiplier. The proof shows why that block can repeat, and how the multiplier controls a full-state period. Normalizing away amplitude would invalidate this conclusion.

At the studied settings, a finite return must stay below a proved amplitude ceiling. **The 60-degree strengthening is supported:** if a regular finite return ever has all three ordinary complex phases inside a closed 60-degree arc, it must be a fixed state. Positive mixing strictly narrows a positive-width sector; the simultaneous phase update cannot widen it. An aligned finite return cannot cycle because its amplitude potential strictly decreases unless it is fixed.

This 60 degrees measures spread of complex channel phases. It is not the geometric angle between cone axes.

A genuine three-update return, if one exists in the remaining domain, can leave a principal common-phase remainder of at most about **18.5474 degrees**. This rules out the specific three-update return with a quarter-turn complex phase remainder. It does not rule out every twelve-update orbit, every three-stage coherence orbit or motion in general.

The completed search tried 60 prescribed starts. Forty-two reached numerical lower-period outcomes in seven groups; 17 failed in the line search and one reached the iteration ceiling. There was no genuine three-stage candidate or certificate attempt. A finite search finding no candidate does not prove that none exists.

The existing cubic innovation can detect a common phase that coherence hides. That does not make it a measured energy flux or establish a moving cone. No opening has been identified here as an energy outlet. The specific native-to-cone correspondence remains unestablished.
