The stationary state and conjugate relative equilibria are inherited constructions. The matched
comparison places their distinct advances beside a common assigned diagnostic. Neither the
coeﬃcient tuple nor that diagnostic, even together, chooses which state is actually realized. The
positive chirality label ﬁxes a reference; its rate has the sign of A and need not be positive for
an arbitrary ordering of distinct coeﬃcients.
Conjugation leaves the ordered real coeﬃcients and the positive real r ﬁxed while reversing
the chiral rate. Pure site reﬂection instead carries the coeﬃcients and changes the chirality
label while preserving the scalar rate of the reﬂected state. These transformations must not be
interchanged. Gauge restoration by a common phase changes neither rate nor branch label [ 2,
D28–D30].
Once a chiral branch is speciﬁed, the exact relationship is compatible with this limitation. For
h>0,
ν± = ±Θ C h3 , ω ± = ±Θ C h2 . (8.2)
These are identities between functions on diﬀerent selected backgrounds. They do not describe
a force, transfer, state switch or trajectory from r to z±. They are not state-independent laws
for arbitrary native states.
8.1 Compatibility with deterministic reconstruction
The full native state remains deterministic: one state at one parameter tuple has one next state.
Table 2 never holds the full state ﬁxed. It also does not show that every possible state-dependent
response observation is insuﬃcient. In particular it does not identify the response matrix at a
chiral state with Jh at r.
The accepted phase-reconstruction theorem recovers full state histories once the required re-
tained coordinates and initial common phase are supplied on its admitted coherent domain [ 4,
thm:reconstruction, thm:phasebranch]. That narrow ordinary-phase domain does not con-
tain the twisted references used here. Its established determinism is preserved, without extending
its domain or substituting one scalar diagnostic for its data.
