The owner authorized this repository edition, authorship and AI-assistance disclosure. The recorded reviews and reciprocal checks were **project-internal, not external peer review**. This paper edition is separate from the software version, Papers A-G, any tag or DOI. Publication makes no kernel, API, UI or runtime changes.

The paper studies exactly one update of the fixed positive input family `a*(1,2,1)` at the recovered coefficients. It distinguishes population ambiguity from exact signed-output and normalized-coherence identifiability on that family. The negative RFO-02 classification result, adopted gain/readout assumptions, entrance-intensity and direct-formula comparators, and absence of an established computational advantage are retained. It establishes neither generic kernel inversion, phase-error robustness, physical realization nor installed-UI certification.
