# Editorial notation crosswalk

Final manuscript: Appendix B, Table 4 (p. 16).


These are editorial names for existing quantities, not new definitions or assumptions.

| Meaning | Existing source notation | Manuscript notation |
| --- | --- | --- |
| Diagnostic ball radius | Central-route \(\rho\) | \(R_B\) |
| Cylindrical radius about the axis through O | Six-opening \(\rho(P)\) | \(r_\perp(P)\) |
| Receiver state | \(z\in\mathbb R^2\) | \(z\) |
| Centered spatial height | z, w or \(\zeta\) in geometry sources | \(\zeta(P)\) |
| Common host width | \(w\) in S03 | \(w_{\rm host}\), or w clearly separated from the characteristics |
| Carrier characteristics | \(w_\pm\) | \(w_\pm\), with host-width notation kept distinct |
| Native source Jacobian | \(J=D_xf\) | \(J_f\) |
| Horizontal quarter-turn | \(J(X,Y)=(-Y,X)\) | \(J_\perp\) |
| Static geometry parameter | \(\tau\) | \(\tau_g\) |
| Carrier/exchange time | t; integration dummy sometimes \(\tau\) | t, with t' as an integration dummy |
| Geometry half-height | h in CG | \(h_g\) |
| Exchange dwell duration | h in hybrid | \(h_{\rm ex}\) |
| Contact arclength offset | \(\eta,\eta_{\rm geom},\eta_g\) | \(\eta_g\) |
| Native and receiver multipliers | \(\eta,\kappa\) or \(\eta_N,\eta_R\) | \(\eta_N,\eta_R\) |
| Circle offset / plane constant | \(\kappa,K_c\) in PG/CR | \(K_c\) |
| Carrier circle radius | \(R_\Gamma,R_c\) | \(R_\Gamma\) |
| Raw source gain | G | \(G_{\rm gain}\) |
| Central boundary arcs | \(G_k^\sigma\) | \(G_k^\sigma\) |
| Source support union | S | \(\mathcal S_b\) |
| Centered MINUS reflection | S | \(S_{\rm ref}\) |
| Circle angle versus arclength | \(\Gamma_j(\theta)\), \(\Gamma(s)\) | Define \(\gamma_j(s)=\Gamma_j(s/R_\Gamma)\) explicitly |
| Lower central vertices versus circle center | \(B_i\), \(B_j\) | Retain \(B_i\) for lower vertices and use \(C_j^\Gamma\) for the circle center if needed |

The manuscript uses these names, with R_Γ for the carrier radius and O + K_c u_j written directly for a circle center. The full typeset crosswalk is Appendix B, Table 4. Central sets are displayed in O-centered coordinates and translated by O in world-space incidence and distance comparisons.
